# SOAR-cybersecurity
This repository contains notes and key takeaways from completing the Introduction to SOAR room on TryHackMe. The room introduced the fundamentals of Security Orchestration, Automation, and Response (SOAR) and explained how modern Security Operations Centres (SOCs) use automation to improve incident response and security operations.

# Scenario A SOC team experienced delays during a major breach investigation due to limited automation capabilities. To improve incident response efficiency, McSkidy recommended implementing a SOAR platform with automated workflows (playbooks). This task focused on configuring and testing a Threat Intelligence integration workflow to automate parts of the investigation process. --- # Objective Configure the workflow components correctly to create a successful automated threat intelligence playbook. The workflow required: - Activating the correct workflow elements - Connecting integrations properly - Running and testing the playbook - Ensuring smooth execution across the flowchart --- # Workflow Process ```mermaid graph TD; A[Security Alert Triggered] --> B[Extract IOC] B --> C[Threat Intelligence Lookup] C --> D{IOC Malicious?} D -->|Yes| E[Generate Incident] D -->|No| F[Close Alert] E --> G[Notify SOC Team] ``` --- # Key Concepts Learned ## Security Orchestration Connecting security tools and systems together to improve operational efficiency. ## Security Automation Reducing manual investigation tasks through automated workflows. ## Threat Intelligence Integration Automatically enriching alerts with external intelligence sources. ## Playbooks Predefined automated workflows designed to handle security events consistently. --- # Skills Developed ```bash + Workflow Configuration + Threat Intelligence Enrichment + SOC Automation Concepts + Incident Response Logic + Playbook Testing + Security Operations Awareness ``` --- # Outcome Successfully configured and tested the Threat Intelligence workflow with a smooth automated execution path across all stages of the playbook. --- # Tools & Concepts | Area | Description | |------|-------------| | SOAR | Security Orchestration, Automation & Response | | IOC | Indicators of Compromise | | Playbooks | Automated response workflows | | Threat Intel | External intelligence enrichment | | SOC | Security Operations Centre |
